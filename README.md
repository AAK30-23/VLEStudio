# VLE Studio

Приложение для расчёта и визуализации фазового равновесия в бинарных системах «жидкость–пар» (VLE, Vapor–Liquid Equilibrium).

Проект разрабатывается на C++ с использованием Qt Widgets. Термодинамические расчёты выполняются на Python с библиотекой `thermo`; взаимодействие C++ и Python организовано через `pybind11`. Результаты расчётов сохраняются в SQLite.

## 1. Цель проекта

Разработать приложение для исследования фазового равновесия двухкомпонентных смесей:

- этанол – вода (`ETHANOL_WATER`);
- ацетон – хлороформ (`ACETONE_CHLOROFORM`).

Предусмотреть два подхода к моделированию:

- **Peng–Robinson (φ–φ)** — уравнение состояния Peng–Robinson для описания обеих фаз;
- **UNIFAC + Peng–Robinson (γ–φ)** — модель коэффициентов активности UNIFAC для жидкой фазы и уравнение Peng–Robinson для паровой фазы.

Планируемые режимы расчёта:

- расчёт равновесия в одной точке при заданных температуре, давлении и составе;
- построение диаграммы T–x–y при заданном давлении;
- построение диаграммы P–x–y при заданной температуре;
- определение азеотропной точки;
- при необходимости — оценка параметра бинарного взаимодействия `k_ij` по экспериментальным данным.

### 3.2. Интеграция Python и C++

- Настроен вызов Python из C++ через `pybind11`.
- Подключён Python-модуль расчётов.
- Работает вызов `calculate_point` для расчёта одной точки обеих смесей по обеим моделям.
- Результаты Python передаются в C++ и отображаются в приложении.
- Реализованы функции `calculate_txy`, `calculate_pxy` и `calculate_azeotrope` по контракту из раздела 6. В расчётах поддерживаются обе смеси (`ETHANOL_WATER`, `ACETONE_CHLOROFORM`) и обе модели (`PR`, `UNIFAC_PR`).
- Расчёты T–x–y и P–x–y подключены к интерфейсу: кривые строятся на `DiagramWidget`, результаты выводятся в таблицу, азеотроп отмечается на графике.

Точность моделей проверена по экспериментальным данным (раздел 4.2): для UNIFAC + Peng–Robinson среднее отклонение температуры составляет менее 1 K, для Peng–Robinson без подгонки `k_ij` — заметно больше.

## 6. Предлагаемый контракт Python-функций

Предлагаемые сигнатуры для реализации:

```python
calculate_txy(
    temperature_min_K,
    temperature_max_K,
    pressure_Pa,
    n_points,
    mixture,
    model
)

calculate_pxy(
    temperature_K,
    pressure_min_Pa,
    pressure_max_Pa,
    n_points,
    mixture,
    model
)
```

Коды смесей:

- `ETHANOL_WATER`
- `ACETONE_CHLOROFORM`

Коды моделей:

- `PR`
- `UNIFAC_PR`

Предлагаемый формат результата T–x–y:

```python
{
    "temperature_K": [...],
    "x1": [...],
    "y1": [...],
    "azeotrope": {
        "temperature_K": ...,
        "x1": ...
    }
}
```

Предлагаемый формат результата P–x–y:

```python
{
    "pressure_Pa": [...],
    "x1": [...],
    "y1": [...],
    "azeotrope": {
        "pressure_Pa": ...,
        "x1": ...
    }
}
```

Это согласованный интерфейс взаимодействия, реализованный в проекте.

### 6.1. Реализация контракта

Функции `calculate_txy` и `calculate_pxy` реализованы в `python/vle_calc.py` в соответствии с этим контрактом.

- Обе функции принимают необязательные аргументы `n_points` (по умолчанию 51), `mixture` (`ETHANOL_WATER`), `model` (`PR`) и `kij` (параметр бинарного взаимодействия для Peng–Robinson, по умолчанию 0).
- Точки диаграммы строятся по составу жидкости: `x1` равномерно изменяется от 0 до 1, для каждой точки вычисляется температура (или давление) начала кипения и состав пара `y1`. Кривая жидкости строится по `x1`, кривая пара — по `y1`.
- Аргументы `temperature_min_K` / `temperature_max_K` (для T–x–y) и `pressure_min_Pa` / `pressure_max_Pa` (для P–x–y) задают диапазон отображения диаграммы и проверяются на корректность.
- Если азеотроп не найден, ключ `azeotrope` содержит `None`. Иначе возвращается словарь с координатами азеотропной точки.
- Значения возвращаются обычными списками Python (`list`), чтобы их можно было напрямую передать в C++ через `pybind11`.
- Не сошедшиеся точки пропускаются; если сошлось меньше двух точек, выбрасывается `RuntimeError`.

Дополнительно реализованы:

- `calculate_point(T, P, x1, mixture, model, kij=0.0)` — расчёт одной точки для любой смеси и модели;
- `calculate_azeotrope(pressure_Pa, mixture, model, n_points=101)` — отдельный поиск азеотропа при заданном давлении;
- `python/experimental_data.py` — экспериментальные данные при атмосферном давлении;
- `python/vle_analysis.py` — сравнение с экспериментом, оценка точности (`compare_with_experiment`, `evaluate_models`) и подбор `k_ij` (`fit_binary_interaction_parameter`).

Тесты функций находятся в `tests/test_vle_calc.py` и `tests/test_vle_analysis.py`.

## 7. Установка и запуск

### Системные зависимости

Для Ubuntu 24.04 потребуются:

- компилятор C++;
- CMake;
- Qt 6 Widgets и Qt 6 SQL;
- SQLite-драйвер для Qt;
- Python 3.12 и заголовочные файлы Python;

### Python-окружение

Из корневой папки проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install thermo==0.6.1 scipy pybind11
```

### Сборка

```bash
cmake -S . -B build
cmake --build build -j2
```

### Запуск

```bash
./build/VLEStudio
```

### Тесты

```bash
python -m unittest discover -s tests
```

### Сравнение с экспериментом и подбор k_ij

Из корневой папки проекта:

```bash
cd python
python vle_analysis.py
```

Скрипт выводит средние и максимальные отклонения расчёта от экспериментальных данных для обеих смесей и моделей, а также подобранные значения `k_ij`.
