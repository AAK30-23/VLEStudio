# VLE Studio

Приложение для расчёта фазового равновесия в бинарных смесях
жидкость–пар.

## Технологии

- C++17
- Qt 6 Widgets
- Python
- thermo
- pybind11
- SQLite (планируется)

- [x] Подключён Python через pybind11.

## Настройка Python

На Ubuntu создайте виртуальное окружение:

    python3 -m venv .venv

Активируйте его:

    source .venv/bin/activate

Установите зависимости:

    python -m pip install --upgrade pip
    python -m pip install thermo scipy

## Сборка

Установите системные зависимости Qt 6, CMake, Ninja,
компилятор C++ и pybind11.

Затем из корня проекта выполните:

    cmake -S . -B build -G Ninja
    cmake --build build

Запуск:

    ./build/VLEStudio

## Структура проекта

- `src/` — код C++ и интерфейс Qt.
- `python/` — термодинамические расчёты.
- `data/` — данные для расчётов и проверки.
- `tests/` — тесты.
- `docs/` — документация проекта.

## Важно

Текущий расчёт этанол–вода — предварительный тест интеграции,
а не подтверждение точности модели. Результаты необходимо
сверить с экспериментальными данными и эталонными расчётами.
