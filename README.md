# VLE Studio

Приложение для расчёта и визуализации фазового равновесия в бинарных системах «жидкость–пар» (VLE, Vapor–Liquid Equilibrium).

Проект разрабатывается на C++ с использованием Qt Widgets. Термодинамические расчёты выполняются на Python с библиотекой `thermo`; взаимодействие C++ и Python организовано через `pybind11`. Результаты расчётов сохраняются в SQLite.

## 1. Цель проекта

Разработать приложение для исследования фазового равновесия двухкомпонентных смесей:

- этанол – вода (`ETHANOL_WATER`);
- ацетон – хлороформ (`ACETONE_CHLOROFORM`).

Предусмотреть два подхода к моделированию:

- **Peng–Robinson (φ–φ)** — уравнение состояния Peng–Robinson для описания обеих фаз;
- **UNIFAC + Peng–Robinson (γ–φ)** — модель коэффициентов активности UNIFAC для жидкой фазы и уравнение Peng–Robinson для паровой фазы.

Планируемые режимы расчёта:

- расчёт равновесия в одной точке при заданных температуре, давлении и составе;
- построение диаграммы T–x–y при заданном давлении;
- построение диаграммы P–x–y при заданной температуре;
- определение азеотропной точки;
- при необходимости — оценка параметра бинарного взаимодействия `k_ij` по экспериментальным данным.

## 3. Текущая реализация

### 3.1. Интерфейс Qt / C++

Реализовано:

- главное окно приложения;
- выбор бинарной смеси;
- выбор режима расчёта: одна точка, T–x–y или P–x–y;
- выбор термодинамической модели;
- поля ввода температуры, давления и мольной доли первого компонента;
- поля для задания диапазонов температуры и давления в режимах построения диаграмм;
- настройка количества точек расчёта;
- изменение подписей и доступности элементов интерфейса в зависимости от выбранной смеси и режима;
- проверка корректности диапазонов температуры и давления;
- прокручиваемая область интерфейса;
- область для отображения диаграмм (`DiagramWidget`).

**Важно:** поля и интерфейс для режимов T–x–y и P–x–y подготовлены, но сами термодинамические расчёты и построение диаграмм ещё не подключены.

### 3.2. Интеграция Python и C++

- Настроен вызов Python из C++ через `pybind11`.
- Подключён Python-модуль расчётов.
- Работает вызов функции `calculate_pr` для предварительного расчёта одной точки системы этанол–вода по Peng–Robinson.
- Результаты Python передаются в C++ и отображаются в приложении.

Текущий расчёт одной точки — проверка интеграции и базовой работоспособности приложения. Его точность необходимо отдельно проверять по экспериментальным данным.

### 3.3. История расчётов и SQLite

Реализовано:

- создание и использование SQLite-базы;
- сохранение результатов расчёта одной точки;
- отображение истории расчётов;
- просмотр подробностей выбранной записи;
- сортировка истории;
- удаление отдельных записей;
- экспорт истории в CSV.

Текущая структура хранения рассчитана на результаты одной точки. Для сохранения массивов данных диаграмм может потребоваться расширение схемы базы.

### 3.4. Сборка

Проект собирается через CMake. Проверена сборка и запуск приложения в Ubuntu 24.04 в виртуальной машине VirtualBox.

## 7. Установка и запуск

### Системные зависимости

Для Ubuntu 24.04 потребуются:

- компилятор C++;
- CMake;
- Qt 6 Widgets и Qt 6 SQL;
- SQLite-драйвер для Qt;
- Python 3.12 и заголовочные файлы Python;
- pybind11.

### Python-окружение

Из корневой папки проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install thermo==0.6.1 scipy pybind11
```

### Сборка

```bash
cmake -S . -B build
cmake --build build -j2
```

### Запуск

```bash
./build/VLEStudio
```
